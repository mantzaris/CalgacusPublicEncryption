# Manuscript claim-to-evidence map

Internal provenance, deliberately outside the anonymous PDF. Source-evidence snapshot: **87cc8c8394a1e1b370825cf565bb0e132da14954**. The paper draft is later host-only work. Original reports, configurations, keys, carriers, traces and ledger were not rewritten. The original [blueprint](../PAPER_BLUEPRINT.md) and [claim matrix](../CLAIM_EVIDENCE_MATRIX.md) remain intact.

[Machine-readable claim evidence](review/claim_evidence.json) indexes immutable attempt IDs, original GPU source revisions, profile identities/hashes, exact carrier paths and trace paths. [Asset verification](review/asset_verification.json) hashes every consumed artifact and records numerical checks. [Generated recovery](generated/recovery.json), [scores](generated/scores.csv), [predicates](generated/predicates.json) and [AUC](generated/auc.json) contain unrounded values behind the displayed rounding. This file explains the denominator and scientific role of each source.

## Attribution outside the anonymous manuscript
