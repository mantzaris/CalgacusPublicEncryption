# Interpretation constraints retained during execution

The fresh matrix has one repetition per setting, eight independently generated recipient keys, and four development-informed contexts. It is not a population-level reliability study. No failed attempt is replaced, and controls of failed R transmissions use the predeclared 1,984-token fallback.

Useful bits per token has two distinct meanings here. Successful-message rate divides recovered payload bits by actual delivered carrier tokens. The attempt-level mean assigns zero useful rate to an aborted or unrecovered transmission; this is a convention over attempted messages, not a claim that an internal aborted token stream appeared on a network. Recovered bytes per conservative charged second includes failed attempts, startup, and all passes. Partial bit progress is never counted as payload recovery.

Recognition primary scores use complete received messages and their matched, scorable B controls, independent of private authentication outcomes. A matched control does not turn a delivery-conditioned analysis into an unconditional traffic model. Controls belonging to aborted sources remain in the records and descriptive counts, but are excluded from matched delivered-message AUCs. Joint-support R-minus-F comparisons add the requirement that both methods and both controls deliver scorable text. Report the actual pair and context counts.

AUC orientation is frozen higher-is-carrier. An AUC below0.5 is not silently reversed; it can indicate separation in the opposite direction. Complete separation or an all-success bootstrap can yield a degenerate interval in a small sample. Neither guarantees population performance. Length-conditioned token-count AUC is mechanically0.5 when matched counts coincide. Byte counts may differ despite matched token counts.

The complete-message X25519 representation check is only necessary, not sufficient, for a valid encapsulation. Public arithmetic extraction checks packet completion and the declared canonical termination rule, not HPKE authentication. B uses the original unrounded probabilities; R uses the fixed integer approximation. Per-step total variation reports that difference where public logits were scored; it is not an additional model pass or an optimized ablation.

The diagnostic historical HPKE packet opens under its original Stage7 binding. It is not a fresh Stage8-bound message. The extended trajectory can show completion after1536 without changing the old1536-token failure. Fresh Stage8 ciphertexts have independent encryption randomness and cannot be treated as paired old/new-budget packets. The nested512/1024/1536/1984 checkpoints of each single fresh trajectory provide the capacity comparison.

Cross-method recognition differences combine mapping, realized length and delivered-path conditioning. R's scarce delivered cases must not be compared with all F cases as if their supports were identical: the joint-support analysis uses the same delivered context/size/key groups for both methods and their respective length-matched controls. Even that comparison is not an unconditional traffic experiment or a causal isolation of termination from every other property. Bootstrap draws with no available scored pair are undefined and their counts are recorded.

The host analysis implements the frozen size-stratified bootstrap rule for both recovery and recognition: resample contexts only within a fixed payload class, retaining its repetitions. A host-script draft initially reused the mixed-size key-group draw for the recovery table; it was corrected before final analysis to conform to the committed specification. No inference, source packet, outcome, score definition or experimental setting changed.
